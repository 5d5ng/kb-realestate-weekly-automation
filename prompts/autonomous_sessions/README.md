# 독립 세션 프롬프트

이 폴더의 프롬프트는 역할을 나누기 위한 운영 템플릿이다. 하나의 세션은 하나의 프롬프트만 사용하고, 다른 세션의 역할을 대신하지 않는다.

## 실행 규칙

1. 디렉터가 먼저 `run_id`와 입력·출력 파일을 확정한다.
2. 각 세션은 자신에게 지정된 입력만 읽고, 지정된 출력 파일만 새로 쓴다.
3. `status=blocked` 또는 `needs_revision`이면 다음 순서를 건너뛰지 않는다.
4. 작성 세션의 자가 합격은 금지한다. 검수는 `30_editorial_review`와 `60_channel_review`가 담당한다.
5. 실제 외부 게시 권한은 `70_publish`에만 있다. 기본값은 발행하지 않는 `autopublish=false`다.

## 변수 치환

각 프롬프트의 아래 값을 실행 시 실제 경로로 치환한다.

- `{{RUN_ID}}`: 한 번의 실행을 식별하는 값
- `{{RUN_ROOT}}`: `runs/{{RUN_ID}}`
- `{{INPUT_PATH}}`: 직전 단계의 확정 입력
- `{{OUTPUT_PATH}}`: 이 세션만 쓰는 출력 경로
- `{{POLICY_PATH}}`: 사전 확정된 자율 발행 정책 파일
- `{{CHANNEL}}`: `instagram`, `naver_blog`, `telegram` 등

Codex 데스크톱에서 실행할 때는 프롬프트의 지시대로 프로젝트 파일을 읽고 출력 파일을 만든다. 소스 코드 러너에서 실행할 때도 같은 프롬프트와 경로 계약을 사용한다.
